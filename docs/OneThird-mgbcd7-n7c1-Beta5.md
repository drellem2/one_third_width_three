**Status: MEASURED.** The one computation `mg-72e4` could not finish is finished. The `n = 7`
height-1 anchor sweep now covers **163 of 163** isomorphism classes and **227 892 of 227 892**
labelled height-1 vertices, still with **0 violations**.

## 1. What was open

`mg-72e4` measured `β̃_{n−c−1}(Γ(P))` for every height-1 iso class at `n ≤ 7` except one. In its
own words:

> `n=7 c=1` class (42 of 227892 labelled vertices) is **OVER CAP**: Gamma has 30 vertices and
> needs a dim-7 skeleton of 2075235 faces; a targeted run built the skeleton but the rank
> computation had not returned when this was submitted, so `beta~_5` for that class is
> **UNMEASURED**.

The class is `P = {(0,1)}` on `[7]` — a single relation — up to isomorphism, `c = 1`, class size
`7 · 6 = 42`, needed degree `d = n − c − 1 = 5`, and `Γ(P)` has 30 vertices.

It mattered out of proportion to `42 / 227 892` because two of `mg-72e4`'s open remainders
intersect at exactly this class: Conjecture C is unproven, and the `c ≤ 2` cases are not covered
by Conjecture C even if C were proven. Everywhere else the `c ≤ 2` slice rests on measurement;
here it rested on nothing.

## 2. The answer

> **`β̃₅(Γ(P); Q) = 0`** for the `n = 7`, `c = 1` height-1 class.
> Also **`β̃₄(Γ(P); Q) = 0`**.

**These are RATIONAL reduced Betti numbers.** `H̃₅(Γ(P); Q) = 0`. This is *not* a claim that
`Γ(P)` is contractible, and this document does not make that claim anywhere. The
`Q`-acyclicity trap `mg-e08a` documented is honoured in §5.

**Primes used: `2, 3, 5, 7, 46337, 999983, 1000003`.** Every rank in the instrument is computed at
all seven. They agree. The rational conclusion, however, does **not** rest on that agreement — see
§5, which is the point of listing small primes here at all.

## 3. Why the rank computation that was in flight was never going to return

`mg-72e4` was running sparse elimination on the boundary matrices of `Γ(P)` itself:
`362 740 × 105 032` and `977 320 × 362 740`, seven non-zeros per column, with fill-in. This
instrument does **not** retry that. It replaces it with an exact reduction that leaves three
matrices of **120, 1 680 and 10 920** generators, which run in under a second.

### 3.1 The two structural facts

Write `V = {2,3,4,5,6}`, `m = |V| = 5`. `mg-72e4`'s `atoms_of_upper(P, 7)` returns 30 atoms, each
`tc(P ∪ {r})` for one added relation `r`; re-derived independently here, the 30 `r` are

| set | arcs | count |
|---|---|---|
| `A` | the arcs inside `V` | 20 |
| `B` | `(0, v)`, `v ∈ V` | 5 |
| `C` | `(v, 1)`, `v ∈ V` | 5 |

A subset `S` of atoms is a face of `Γ(P)` iff `tc(P ∪ S)` is a **non-total partial order**. Split
that predicate in two:

**(1) Acyclicity is carried by `A` alone.** `0` has no in-arc and `1` has no out-arc among the 30,
so every directed cycle lies inside `V`. Hence `tc(P ∪ S)` is a partial order iff `S ∩ A` is an
acyclic digraph on `V`. The "partial order" half of the predicate therefore defines

```
X  :=  σ(B ∪ C)  *  K_m ,        K_m := the acyclic-subgraph complex on the arcs of V
```

the join of a **full simplex** on the 10 vertices `B ∪ C` with `K_m`. A join with a non-empty
simplex is a **cone**, so `X` is contractible.

**(2) Totality is a filter generated in one degree — and it is the degree in question.**
`tc(P ∪ S)` is total iff it is the linear order `0 < v₁ < … < v₅ < 1` for some ordering of `V`
(`0` must be the minimum and `1` the maximum, again because `0` is a source and `1` is a sink).
Its cover arcs `(0,v₁), (v₁,v₂), …, (v₄,v₅), (v₅,1)` are `m + 1 = 6` atoms and all six are needed.
So the excluded faces are exactly the filter `F` generated by `5! = 120` sets of size 6 — i.e.
**120 faces of dimension 5**, and `5 = n − c − 1` is precisely the target degree.

```
Γ(P) = X \ F
```

**This is where the naive version of this argument fails, and it is worth recording.** A first
pass at (2) put the excluded faces at size 14 (all of `B ∪ C`, plus a total order on `V`), which
would have made `Γ` agree with the contractible `X` through dimension 12 and handed back
`β̃₅ = 0` for free. That is wrong: transitivity supplies the rest of `B` and `C`, so a single
`(0,v₁)` and a single `(v₅,1)` suffice. The error was caught by the direct sweep in §4 — the
measured dimension-5 face count is `362 740`, exactly `120` short of `X`'s `362 860`. The removed
filter starts **in the target degree**, so the answer is not free and had to be computed.

### 3.2 The reduction

`X` is contractible, so the long exact sequence of the pair `(X, Γ)` gives

```
H̃_d(Γ)  ≅  H_{d+1}(X, Γ)      for every d,
```

and the relative chain complex is free on `F`, which is empty below dimension `m = n − 2 = 5`.
So

- `β̃₄(Γ) = H₅(X, Γ) = |C₅(F)| − rank ∂₆`, and
- `β̃₅(Γ) = H₆(X, Γ) = (|C₆(F)| − rank ∂₆) − rank ∂₇`,

with `|C₅(F)| = 120`, `|C₆(F)| = 1 680`, `|C₇(F)| = 10 920`. Measured at every prime:

| prime | `rank ∂₆` | `rank ∂₇` | `β̃₄` | `β̃₅` |
|---|---|---|---|---|
| 2, 3, 5, 7, 46337, 999983, 1000003 | 120 | 1 560 | **0** | **0** |

`β̃_d(Γ) = 0` for all `d ≤ 3` follows with no computation at all: the relative complex vanishes
below degree 5.

### 4.3 The negative control, including the version that did not work

`V6` substitutes other filters generated in the same degree, inside the same `X`:

| substituted filter | generators | `(β̃₄, β̃₅)` | differs from the true filter |
|---|---|---|---|
| the true filter | 120 | `(0, 0)` | — |
| true filter minus one chain-generator | 119 | `(0, 0)` | no |
| a single chain-generator | 1 | `(0, 0)` | no |
| half the chain-generators | 60 | `(0, 0)` | no |
| **120 non-chain faces of the same size** | 120 | **`(5, 0)`** | **yes** |

The first three perturbations are recorded because they are the ones that **failed to
discriminate**, and that is worth knowing: sub-filters of the true filter also give `(0,0)`, so
"we removed a generator and nothing changed" would have been a vacuous control. Only replacing
the chain-generators with 120 *different* size-6 faces of `X` moves the answer. That is what
establishes the measurement is reading the filter rather than the shape of the code.

## 5. Coefficients — read this before quoting the number

- **`β̃₅ = 0` here is a rational Betti number.** `H̃₅(Γ(P); Q) = 0`. Nothing in this document says
  `Γ(P)` is contractible, `Z`-acyclic, or has vanishing homotopy.
- **The rational conclusion does not rest on prime agreement.** `rank_{F_p} ≤ rank_Q` for every
  `p`, hence `β_Q ≤ β_{F_p}`. So a **single** prime with `β_{F_p} = 0` forces `β_Q = 0`. This is
  one-way and it is the direction that is safe. The reverse — inferring a rational value from
  agreeing mod-`p` values — is the `mg-e08a` trap, and it is not used.
- **What the small primes buy is torsion, not confidence in the rational answer.** The ranks are
  identical at `p = 2, 3, 5, 7`, so `H₅` and `H₆` of the pair `(X, Γ)` carry no `p`-torsion for
  those `p`. Nothing here rules out torsion at other primes, and nothing here is a statement about
  `Γ(P)`'s integral homology in general.
- `mg-72e4`'s two-prime measurements are not retracted or upgraded by this. This document adds one
  class to its table and leaves the coefficient caveat on the rest of the table exactly as it was.

## 6. Independent confirmation, and what the gap actually was

`p9cd1` (work item `mg-9cd1`, the independent audit of `mg-72e4`) measured the same class
**by a route that shares nothing with this one**: no decomposition, no LES — its own atoms, its
own DFS on the face rule, 1 470 787 faces through dimension 6, mod-2 rank. It gets `β̃₅ = 0` and
`β̃₄ = 0`. Two routes about as unlike as two routes to this number can be.

It also measured `Γ`'s dimension-7 face count by enumeration, before reading any of this, and
gets `2 075 235`.

**`p9cd1`'s diagnosis of why the class was excluded, which is more useful than "we finished the
hard one" and is recorded here as its observation:** `mg-72e4`'s over-cap test is a binomial
bound on the **ambient simplex** on 30 atoms —
`_binom(len(atoms), d+3) = C(30,8) = 5 852 925 > 3 000 000` — not a count of `Γ`'s faces. The
real `Γ` is much thinner. From the f-vector in §4.1:

| quantity | faces |
|---|---|
| what the cap test compared against (ambient `C(30,8)`) | 5 852 925 |
| `Γ` through dim 7 (what the script sizes, because it also reports `betti_one_above`) | 3 546 022 |
| **`Γ` through dim 6 (all `β̃₅` actually needs)** | **1 470 787** |
| `mg-72e4`'s cap | 3 000 000 |

So two things had to line up. The cap was tested against an ambient bound roughly **4×** the
object; **and** the skeleton being sized was one degree deeper than the target degree required.
Fix either one and the class comes inside the cap: `1 470 787 < 3 000 000`. It was never a
computational wall. (The `1 470 787` is `p9cd1`'s by enumeration and this document's by closed
form, independently.)

## 7. Extension: the `c = 1` class beyond `n = 7`

The same reduction is cheap at larger `n`, because it never touches `Γ` itself. For the `c = 1`
height-1 class at general `n` (`m = n − 2`), the filter is generated by the `m!` maximal chains
`0 < v₁ < … < v_m < 1`, of size `m + 1` and dimension `m = n − 2 = d`:

| `n` | atoms | `d = n−c−1` | generators | `\|F_{m+1}\|`, `\|F_{m+2}\|`, `\|F_{m+3}\|` | `β̃_{d−1}` | `β̃_d` |
|---|---|---|---|---|---|---|
| 4 | 6 | 2 | 2 | 2, 4, 2 | 0 | **0** |
| 5 | 12 | 3 | 6 | 6, 30, 60 | 0 | **0** |
| 6 | 20 | 4 | 24 | 24, 216, 864 | 0 | **0** |
| **7** | **30** | **5** | **120** | **120, 1 680, 10 920** | **0** | **0** |
| 8 | 42 | 6 | 720 | 720, 14 400, 136 800 | 0 | **0** |
| 9 | 56 | 7 | 5 040 | 5 040, 136 080, 1 769 040 | 0 | **0** |

(`n = 4, 5, 6` are cross-checked against brute force on the entire complex — `V5`. `n = 8` costs
6.2 s and `n = 9` 99.6 s, both over all seven primes; `n = 10` was **not attempted** — the
size-`(m+3)` layer is roughly 19 M faces — and nothing is claimed there.)

**An observed pattern, recorded as a pattern.** At every `n` measured the two relative ranks are
*exactly*

```
rank ∂_{m+2} = |F_{m+1}|            rank ∂_{m+3} = |F_{m+2}| − |F_{m+1}|
```

— the relative complex is exact in both degrees read, which is what makes both Betti numbers
vanish. That is `n = 4 … 9`, and it is **not proved here**. The `c = 1` slice remains
measurement, not theorem. It is written down because it is the shape a proof of the `c = 1` case
would have, and `mg-72e4` §7.5 names exactly that as open.

## 8. What this changes, and what it does not

**Changes.** `mg-72e4`'s `n = 7` row: `162 of 163` → **163 of 163** iso classes, `227 850 of
227 892` → **227 892 of 227 892** labelled vertices, still **0 violations**, **no class over cap**.
The `c ≤ 2` slice is now measured `Q`-acyclic in the anchor degree at every `n ≤ 7` **with no
exception** — the phrase *"the `n = 7` `c = 1` class excepted"* comes out.

**Does not change.**

- **Conjecture C is still unproven.** This is one more measurement, not an argument.
- **The `c ≤ 2` cases still have no proof behind them.** They are now measured without a hole
  rather than measured with one. That is a strictly better evidential position and not a
  different kind of position. §7's pattern is a lead, not a proof.
- **Nothing here is a homotopy statement.** See §5.
- **`mg-72e4`'s other named gap is untouched:** 17 of 163 classes at `n = 7` still have no full
  homotopy type recorded there, and the margin for this class is not computed here. (`p9cd1`
  reports having measured those 17 separately; those are its numbers, not re-derived here, and
  they belong in its document.)
- This does not measure `n ≥ 8` for anything except the `c = 1` class (§7).
