They had **diverged** — 203 differing lines between this file and `union_closed`'s — and two of
the three, including this one, had not been regenerated since **2026-07-29**. This repo took
**six merges on the night of 2026-08-13/14** alone (mg-72e4, mg-9cd1, mg-bcd7, mg-0f24, mg-457a,
mg-3067), so a reader landing here got a sixteen-day-old view with nothing indicating it was
stale. That is a false statement about the product, not merely an old one.

The canonical designation was not new: **this file's own header already read
`onethird_program` (canonical)**. The non-canonical copies simply never got retired. This
finishes a decision that was taken and left half-applied.
